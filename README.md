
# Sistema Integral Software FJ

## Descripción

Sistema desarrollado en Python para gestionar clientes,
servicios y reservas de la empresa Software FJ.

## Objetivo

Implementar una aplicación orientada a objetos que permita
administrar clientes, servicios y reservas, utilizando
validaciones y manejo avanzado de excepciones.

## Funcionalidades

- Registro y validación de clientes.
- Administración de servicios.
- Reservas de salas.
- Alquiler de equipos.
- Asesorías especializadas.
- Confirmación y cancelación de reservas.
- Cálculo de costos, impuestos y descuentos.
- Manejo de excepciones personalizadas.
- Registro de eventos y errores mediante archivos de logs.

## Tecnologías

- Python 3.
- Visual Studio Code.
- Git y GitHub.

## Ejecución

Abrir la carpeta del proyecto en Visual Studio Code
y ejecutar el siguiente comando:

python main.py

## Almacenamiento

El proyecto no utiliza bases de datos.
La información se administra mediante objetos y listas.
Los archivos se utilizan para registrar eventos y errores.
